오늘의 순서

네 단계면 내 앱이 생겨요

1프롬프트 요청제미나이에게 주문서를 써 달라고 해요
2캔버스 실행새 채팅에 붙여넣어 게임을 만들어요
3다운로드게임을 파일로 휴대폰에 저장해요
4홈 화면에 추가바탕화면에 아이콘을 만들어요
오늘의 목표

수업이 끝나면 할 수 있어요

예시를 복사해 제미나이에 프롬프트 요청 문장을 쓸 수 있다.
앱 만들기 4단계를 순서대로 배열할 수 있다.
내 파일에서 게임 파일을 찾아 '홈 화면에 추가'를 선택할 수 있다.
수정 요청으로 효과음과 단계 선택 버튼이 들어가도록 게임을 편집할 수 있다.
1단계

제미나이에 프롬프트 요청하기

1아래 복사하기를 눌러요
2제미나이 앱 → 새 채팅
3입력창 길게 눌러 붙여넣기 → 보내기
4답변 아래 복사 버튼을 눌러요
입력 예시 ① 프롬프트 요청 
제미나이 캔버스에서 시니어용 치매 예방 속담·사자성어 기초 퀴즈 게임 앱을 만들고 싶어.
핸드폰 세로 화면용으로, 글씨와 버튼은 크게, 보기 4개 중 고르는 10문제로.
정답이면 뜻풀이를 보여 주고, 마지막에 점수와 '다시 하기' 버튼.
캔버스에 붙여 넣을 프롬프트를 써 줘.
할 때마다 새로운 문제가 나오도록, 속담과 사자성어 문제를 200개 이상 넣어 두고 그중 10개를 무작위로 골라 내게 해 줘.
보기 순서도 매번 섞이게 하고, 바로 전에 풀었던 문제는 다음 판에 다시 나오지 않게 해 줘.
2단계

새 채팅에 붙여넣고 캔버스 실행

1다시 새 채팅을 열어요
2+ 또는 도구 → 캔버스 켜기
3입력창 길게 눌러 붙여넣기 → 보내기
4잠시 기다리면 게임이 나와요. 풀어 보세요
보충 문장 · 문제가 200개보다 적을 때 
문제가 200개가 안 돼. 겹치지 않는 새 문제를 50개씩 더 추가해 줘. 나머지는 그대로 둬.

보충 문장은 게임을 만든 같은 채팅창에 보내요.

3단계

게임 파일 다운로드

1캔버스 오른쪽 위 공유 또는 ⋮
2다운로드를 눌러요
3내 파일 → 다운로드 폴더에 저장돼요
4단계

내 파일에서 홈 화면에 추가

1내 파일 → 다운로드
2게임 파일을 길게 눌러요
3⋮ 더보기 → 홈 화면에 추가
4바탕화면 아이콘을 눌러 실행해요

처음 열 때 크롬이나 삼성 인터넷을 고르라고 나오면 하나를 고르고 항상을 눌러요.

심화게임 고치기
5단계

효과음 넣기

게임을 만든 그 채팅창에 이어서 보내요. 새 채팅이 아니에요.

입력 예시 ② 효과음 
정답이면 '딩동댕', 틀리면 '삐-' 소리를 넣어 줘.
음원 파일 없이 만들어 줘.
화면 위에 '소리 켜기/끄기' 버튼도 크게 만들어 줘.
나머지는 그대로 둬.

소리가 안 나면 음량 버튼을 올리고 무음 모드를 끈 뒤, 화면을 한 번 누르고 다시 해 보세요.

6단계

단계 선택 버튼 만들기

입력 예시 ③ 단계 선택 
시작 화면에 쉬움·보통·어려움 버튼을 크게 만들어 줘.
쉬움은 보기 3개 5문제, 보통과 어려움은 보기 4개 10문제로.
할 때마다 다른 문제가 나오게 해 줘.
효과음과 소리 버튼은 그대로 둬.
7단계

바탕화면 앱 바꾸기

13단계처럼 다시 다운로드
2예전 아이콘을 길게 눌러 삭제
3새 파일로 4단계를 다시 해요. 이름 끝에 (1)이 붙어 있어요
4앱을 열어 소리와 단계 버튼을 확인해요
뜻풀이가 이상하면 같은 채팅창에 "이 문제 뜻이 맞는지 확인하고 고쳐 줘"라고 보내세요.
