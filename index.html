2캔버스 실행새 채팅에 붙여넣어 게임을 만들어요
3다운로드게임을 파일로 휴대폰에 저장해요

오늘의 목표

수업이 끝나면 할 수 있어요

예시를 복사해 제미나이에 프롬프트 요청 문장을 쓸 수 있다.
앱 만들기 4단계를 순서대로 배열할 수 있다.
내 파일에서 게임 파일을 찾아 '홈 화면에 추가'를 선택할 수 있다.
수정 요청으로 효과음과 시작 난이도 버튼이 들어가도록 게임을 편집할 수 있다.
1단계

제미나이에 프롬프트 요청하기

1아래 복사하기를 눌러요
2제미나이 앱 → 새 채팅
3입력창 길게 눌러 붙여넣기 → 보내기
4답변 아래 복사 버튼을 눌러요
입력 예시 ① 프롬프트 요청 
제미나이 캔버스에서 시니어용 치매 예방 숫자 순서 터치 게임 앱을 만들고 싶어.
핸드폰 세로 화면용으로, 글씨와 숫자 칸은 크게.
30초 동안 1부터 30까지 숫자가 무작위로 흩어진 칸에서, 숫자를 순서대로 눌러 하나씩 지우는 게임이야.
순서가 틀리면 칸이 흔들리기만 하고, 다 지우면 통과야.
통과할 때마다 단계가 올라가면서 점점 어려워지게 해 줘. (제한 시간이 줄고, 숫자 자리가 중간에 섞이고, 나중에는 30부터 거꾸로 누르기)
시간이 끝나면 지운 개수와 '다시 하기' 버튼.
캔버스에 붙여 넣을 프롬프트를 써 줘.
할 때마다 숫자 배치가 새로 섞이게 해 줘.
2단계

새 채팅에 붙여넣고 캔버스 실행

1다시 새 채팅을 열어요
2+ 또는 도구 → 캔버스 켜기
3입력창 길게 눌러 붙여넣기 → 보내기
4잠시 기다리면 게임이 나와요. 풀어 보세요
보충 문장 · 칸이 작거나 다음 단계가 안 나올 때 
숫자 칸이 작아서 누르기 어려워. 칸과 글씨를 더 크게 키워 줘. 통과하면 '다음 단계로' 버튼이 나오게 해 줘. 나머지는 그대로 둬.

보충 문장은 게임을 만든 같은 채팅창에 보내요.

3단계

게임 파일 다운로드

1캔버스 오른쪽 위 공유 또는 ⋮
2다운로드를 눌러요
3내 파일 → 다운로드 폴더에 저장돼요
4단계

내 파일에서 홈 화면에 추가

1내 파일 → 다운로드
2게임 파일을 길게 눌러요
3⋮ 더보기 → 홈 화면에 추가
4바탕화면 아이콘을 눌러 실행해요

처음 열 때 크롬이나 삼성 인터넷을 고르라고 나오면 하나를 고르고 항상을 눌러요.

심화게임 고치기
5단계

효과음 넣기

게임을 만든 그 채팅창에 이어서 보내요. 새 채팅이 아니에요.

입력 예시 ② 효과음 
맞는 숫자를 누르면 '딩동', 틀린 숫자를 누르면 '삐-' 소리를 넣어 줘.
음원 파일 없이 만들어 줘.
화면 위에 '소리 켜기/끄기' 버튼도 크게 만들어 줘.
나머지는 그대로 둬.

소리가 안 나면 음량 버튼을 올리고 무음 모드를 끈 뒤, 화면을 한 번 누르고 다시 해 보세요.

6단계

시작 난이도 버튼 만들기

입력 예시 ③ 시작 난이도 
시작 화면에 쉬움·보통·어려움 버튼을 크게 만들어 줘.
쉬움은 숫자 1~20에 40초, 보통은 숫자 1~30에 30초, 어려움은 숫자 1~30에 25초로 하고 숫자 자리도 중간에 섞이게 해 줘.
할 때마다 숫자 배치가 새로 섞이게 해 줘.
효과음과 소리 버튼은 그대로 둬.
7단계

바탕화면 앱 바꾸기

13단계처럼 다시 다운로드
2예전 아이콘을 길게 눌러 삭제
3새 파일로 4단계를 다시 해요. 이름 끝에 (1)이 붙어 있어요
4앱을 열어 소리와 난이도 버튼을 확인해요
게임이 이상하게 움직이면 같은 채팅창에 "이 부분이 이상해, 고쳐 줘"라고 보내세요.
