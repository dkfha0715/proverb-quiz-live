0단계

바이브 코딩 이야기

바이브 코딩이란"프로그램 언어를 몰라도, 만들고 싶은 것을 우리말로 설명하면 AI가 대신 만들어 주는 방법이에요."
이름의 뜻"2025년 초 AI 개발자 안드레이 카파시가 처음 쓴 말이에요. '바이브'는 느낌이에요. '이런 느낌으로 만들어 줘' 하고 맡긴다는 뜻이에요."
예전과 지금예전: 언어 배우기 몇 달, 영어 명령어, 오류는 직접 고치기
지금: 우리말로 바로, "고쳐 줘" 한마디
'프롬프트'라는 말"AI에게 보내는 주문서를 프롬프트라고 해요. 오늘 이 말이 자주 나와요."
이런 것도 만들어요약 먹을 시간 체크표, 손주와 가족 퀴즈, 모임 회비 계산기, 가계부, 걷기 기록장
즉석 시연강사 휴대폰 화면을 띄우고 아래 시연 문장을 캔버스에 보내 금방 나오는 결과를 함께 봐요.
잘 주문하는 요령 3가지① 누가 쓰는지 말하기
② 한 번에 하나씩 고치기
③ 마음에 안 들면 다시 말하기
주의할 점"AI도 틀릴 수 있어요. 이상하면 고쳐 달라고 하세요. 이름·전화번호는 넣지 마세요."
오늘 만들 것완성된 퀴즈 앱을 보여 주며 "오늘 끝나면 여러분 바탕화면에도 이 아이콘이 생겨요."
즉석 시연 문장 · 강사 휴대폰, 캔버스 켜고 
손주 생일 축하 카드 만들어 줘. 풍선이 아래에서 위로 날아오르고, 가운데에 '사랑하는 우리 손주 생일 축하해'가 크게 나오게.
강사 진행 포인트
끝에 "요령 세 가지가 뭐였죠?" 하고 수강생이 직접 말해 보게 해요.
시연 결과가 이상해도 괜찮아요. "다시 말하면 돼요"를 보여 줄 기회예요.
1단계

제미나이에 프롬프트 요청하기

1수강생용 웹교안의 복사하기
2제미나이 앱 → 새 채팅
3입력창 길게 눌러 붙여넣기 → 보내기
4답변 아래 복사 버튼
입력 예시 ① 프롬프트 요청 
제미나이 캔버스에서 시니어용 치매 예방 속담·사자성어 기초 퀴즈 게임 앱을 만들고 싶어.
핸드폰 세로 화면용으로, 글씨와 버튼은 크게, 보기 4개 중 고르는 10문제로.
정답이면 뜻풀이를 보여 주고, 마지막에 점수와 '다시 하기' 버튼.
캔버스에 붙여 넣을 프롬프트를 써 줘.
할 때마다 새로운 문제가 나오도록, 속담과 사자성어 문제를 200개 이상 넣어 두고 그중 10개를 무작위로 골라 내게 해 줘.
보기 순서도 매번 섞이게 하고, 바로 전에 풀었던 문제는 다음 판에 다시 나오지 않게 해 줘.
강사 진행 포인트
"AI에게 주문서를 대신 써 달라고 부탁하는 거예요. 주문서 창과 요리하는 창을 나눠요."
복사 버튼이 없으면 답변을 길게 눌러 '복사'를 선택해요.
화면 아래 최근 앱 버튼(세 줄)으로 웹교안과 제미나이를 오가는 법을 보여 줘요.
2단계

새 채팅에 붙여넣고 캔버스 실행

1다시 새 채팅
2+ 또는 도구 → 캔버스
3붙여넣기 → 보내기
4잠시 뒤 게임을 직접 풀어 봐요
보충 문장 · 문제가 200개보다 적을 때 (같은 채팅창) 
문제가 200개가 안 돼. 겹치지 않는 새 문제를 50개씩 더 추가해 줘. 나머지는 그대로 둬.
강사 진행 포인트
"코드가 흘러가는 건 요리하는 중이에요. 기다리면 돼요."
캔버스가 없으면 앱 업데이트 → 껐다 켜기 → 프롬프트 앞에 "캔버스로 만들어 줘"
코드만 보이면 위쪽 미리보기 탭을 눌러요.
먼저 된 분은 옆 사람과 문제 맞히기를 해요.
3단계

게임 파일 다운로드

1캔버스 오른쪽 위 공유 또는 ⋮
2다운로드
3내 파일 → 다운로드에 저장돼요
강사 진행 포인트
메뉴 이름과 위치는 앱 버전마다 달라요. 전날 캡처한 화면을 보여 줘요.
위에 다운로드 알림이 뜨면 성공이에요.
4단계

내 파일에서 홈 화면에 추가

1내 파일 → 다운로드
2게임 파일 길게 누르기
3⋮ 더보기 → 홈 화면에 추가
4아이콘 눌러 실행. 브라우저를 고르면 항상
강사 진행 포인트
개별 도움이 가장 많은 구간이에요. 보조 강사를 여기에 모아요.
내 파일이 없으면 앱스의 '삼성' 폴더나 검색창에서 찾아요.
아이콘이 안 보이면 바탕화면을 옆으로 넘겨 봐요.
다 함께 박수! "이제 휴대폰에 내가 만든 앱이 생겼어요."
Q&A

진짜 앱이랑 뭐가 달라요?

"오늘 만든 앱은 휴대폰에 저장한 웹페이지 파일에 바탕화면 바로가기를 붙인 거예요. 아이콘을 누르면 인터넷 앱이 그 파일을 열어 보여 줘요."

오늘 만든 앱내가 만든 요리를 도시락에 담아 냉장고에 넣어 둔 것
실제 앱가게에서 사 와서 집에 설치한 가전제품
구분오늘 만든 앱실제 앱 (Play 스토어)
정체웹페이지 파일(HTML) + 바로가기휴대폰에 설치되는 프로그램
받는 곳제미나이 다운로드 → 내 파일Play 스토어 / 갤럭시 스토어
실행인터넷 앱이 열려 보여 줌앱이 바로 실행됨
휴대폰 기능알림·카메라·위치는 거의 못 씀알림·카메라·위치·연락처 사용
업데이트다시 다운로드 후 아이콘 새로 추가스토어에서 자동 업데이트
나눠 주기파일을 카톡으로 보내 바로가기 추가스토어에서 검색해 설치
기록 저장그 휴대폰 인터넷 앱 안에만계정에 저장, 휴대폰 바꿔도 이어짐
드는 것무료, 금방개발자 등록비, 심사, 개발 기간
안전 확인직접 만든 것이라 심사 없음스토어 심사를 거침
강사 멘트 예시
"꺼내 먹기는 똑같이 편하지만, 가전제품처럼 알림을 울리거나 저절로 새것이 되지는 않아요. 대신 내 마음대로 금방 만들 수 있어요."
퀴즈·계산기·기록장은 오늘 방법으로 충분해요. 알림이 오거나 여럿이 함께 쓰는 앱은 실제 앱 개발이 필요해요.

효과음 넣기

게임을 만든 그 채팅창에 이어서 보내요. 새 채팅이 아니에요.

입력 예시 ② 효과음 
정답이면 '딩동댕', 틀리면 '삐-' 소리를 넣어 줘.
음원 파일 없이 만들어 줘.
화면 위에 '소리 켜기/끄기' 버튼도 크게 만들어 줘.
나머지는 그대로 둬.
강사 진행 포인트
예전 채팅 찾기: 제미나이 메뉴(≡) → 최근 대화 목록을 먼저 보여 줘요.
요령 ② "한 번에 하나씩 고치기"를 다시 짚어요.
소리가 안 나면 음량·무음 확인 → 화면 한 번 누르기 → "첫 터치 때 소리가 켜지도록 고쳐 줘"
6단계

단계 선택 버튼 만들기

입력 예시 ③ 단계 선택 
시작 화면에 쉬움·보통·어려움 버튼을 크게 만들어 줘.
쉬움은 보기 3개 5문제, 보통과 어려움은 보기 4개 10문제로.
할 때마다 다른 문제가 나오게 해 줘.
효과음과 소리 버튼은 그대로 둬.

세 단계를 하나씩 눌러 문제 수와 보기 수를 확인해요.
효과음이 사라졌으면 "다시 넣어 줘". 요령 ③ "다시 말하기"의 좋은 예예요.
